# iOS 数据布局与能力限制参考

分析 iOS 扫描结果时读这份。核心结论先行：**iOS 沙盒下无法程序化清理其他 App 的缓存**，本档（guide）只能分析自身沙盒 + 给手动引导，绝不虚报可释放量。

## 为什么清不了

- 每个 App 有独立沙盒（Container），系统不开放"读写其他 App 文件夹"的权限。
- 没有官方的跨 App 缓存清理 API。所谓"iPhone 清理大师"类工具要么只清自身缓存、要么依赖企业证书/越狱（违规且不安全）。
- 因此本 skill 在 iOS 上：能扫描自身沙盒目录，能引导用户手动清理，**不能删任何系统或其他 App 的文件**。

## 可访问范围（自身沙盒）

| 目录 | 装什么 | 处理 |
|---|---|---|
| `~/Library/Caches` | 当前 App 自身缓存 | 🟢 可提示 App 内清理；直接删意义不大且可能被重建 |
| `~/Documents` | 用户文稿 | 🟡 用户数据，引导手动 |
| `~/Library/Application Support` | App 支持数据/数据库 | 🔴 不动 |

注意：在 Pythonista/a-Shell 里跑扫描时，"自身沙盒"是那个 Python 工具的沙盒，**不是微信等目标 App 的沙盒**——所以扫描结果几乎不包含真正占空间的大户。必须在报告里讲清楚这点。

## 正确的手动引导（写进报告）

- **系统层面**：设置 → 通用 → iPhone 储存空间。这里能看到各 App 占用，并提供：
  - 「卸载 App」：删 App 本体、保留文稿与数据（适合想减占用又怕丢数据）
  - 「删除 App」：连同数据一起删（最彻底，先备份）
- **微信 / QQ**：App 内 → 我 → 设置 → 通用 → 存储空间 → 清理缓存。**不要**从文件系统删聊天数据库。
- **Safari**：设置 → Safari 浏览器 → 清除历史记录与网站数据。
- **照片**：删除「最近删除」相簿才会真正释放空间；开启"优化 iPhone 储存空间"。
- **视频/音乐/网盘类**：在各自 App 内删除已下载内容。
- **长期**：iCloud 照片图库 + 优化存储、定期把大文件归档到电脑/NAS、卸载长期不用的 App。

## 分级映射（iOS guide 档）

- 🟢：Safari 网站数据、当前工具自身缓存——**只给引导，不给删除路径/按钮**。
- 🟡：照片、视频、下载文档、聊天数据——给"去哪个 App 清"的引导 + 风险。
- 🔴：App 本体——引导"卸载/卸载重装"。
- `summary.overview` 必须含一句："iOS 沙盒限制下扫描仅覆盖当前环境可见部分，实际占用以系统设置 → iPhone 储存空间为准。"

## 铁律

- `cleanup_mobile.py` 在 iOS 上只打印引导，不执行任何删除。
- 不推荐、不引导越狱或企业证书签名工具。
- 任何声称能"一键清 iPhone 其他 App 缓存"的方案都要提示其风险。
